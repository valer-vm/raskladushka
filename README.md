# Раскладушка

Исправляет текст, набранный не в той раскладке, и переключает раскладку за вас. Для Mac, русский и английский.

`ghbdtn` → `привет`, `руддщ` → `hello`, `gj-heccrb` → `по-русски`, `МЗЫ` → `VPS`.

Сайт: [раскладушка.рф](https://раскладушка.рф)

## Возможности

- **Автоисправление.** Слово исправляется само на пробеле, знаке препинания, Enter или Tab, если в текущей
  раскладке его нет, а в другой оно есть. В Spotlight, Raycast, Alfred, адресной строке Safari и полях поиска — ещё и по паузе в наборе.
- **Двойной Shift** — исправить последнее слово вручную. Если исправление было лишним, двойной Shift вернёт
  слово. Чтобы больше его не исправлять, выберите в меню «Больше не исправлять…».
- **Option + Shift** — перевести в другую раскладку выделенный текст.
- **Регистр:** `ПРивет` → `Привет`, `пРИВЕТ` (задели Caps Lock) → `привет` с выключением Caps Lock.

Слова проверяются по словарям macOS. Для слов, которых в словаре нет (имена, сленг, бренды),
используется статистика буквосочетаний: насколько набор похож на русское или английское слово
(см. `Ngrams.swift` и `tools/gen_ngrams.swift`). Никаких нейросетей и сетевых запросов.

## Приватность

Программа видит каждое нажатие клавиш, поэтому её код открыт для проверки.

- Программа не выходит в интернет.
- История нажатий на диск не записывается. Если замена отменена, перехваченный во время неё текст остаётся в памяти: значок «!» и пункт «Восстановить набранный текст…» позволяют скопировать или удалить его.
- Слова, которые вы попросили не исправлять, хранятся в виде хэшей, а не текстом.
- В полях паролей macOS включает защищённый ввод, и программа их не видит.

## Установка

Готовая сборка — на сайте. Требуется macOS 13 или новее, Apple Silicon или Intel.

Программа не подписана сертификатом Apple, поэтому при первом запуске macOS её заблокирует:
откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.
Затем выдайте разрешение **Универсальный доступ** — программа сама покажет, где.

## Сборка из исходников

Нужны Xcode или Command Line Tools (`xcode-select --install`).

```bash
bash build.sh            # собрать и установить в ~/Applications
bash package.sh          # универсальный zip (Apple Silicon + Intel) для передачи на другой Mac
bash tools/selftest.sh   # тесты логики распознавания без запуска приложения
```

Для тестов в системе должны быть включены английская и русская раскладки.

| Файл | Что это |
|---|---|
| `main.swift` | Приложение: перехват клавиш, распознавание, замена слова, меню |
| `Ngrams.swift` | Статистика троек букв RU/EN, сгенерирована `tools/gen_ngrams.swift` |
| `tools/` | Генератор статистики, тесты, подбор весов |
| `site/` | Сайт программы |
